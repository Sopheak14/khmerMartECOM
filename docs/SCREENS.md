# Screens

Every route is available as `/en/...` and `/km/...`. Screenshots are regenerated by the Playwright run into `docs/screenshots/`.
API paths are relative to `http://localhost:4000/api` (see [API_CONTRACT.md](API_CONTRACT.md)).


## Storefront

### `/`
Home: hero banner (seasonal Pchum Ben banner from the API), flash-sale countdown, the 8 Khmer categories, featured/new/popular products.

- **API:** GET /home, GET /settings/public
- **Screenshots:** [phase1-en.png](screenshots/phase1-en.png), [phase1-km.png](screenshots/phase1-km.png), [phase1-mobile.png](screenshots/phase1-mobile.png)

### `/products`
Catalog: search, facets, sort, pagination, active-filter chips.

- **API:** GET /products, GET /categories
- **Screenshots:** [products-filters-en.png](screenshots/products-filters-en.png), [products-mobile.png](screenshots/products-mobile.png)

### `/category/[slug]`
Category and sub-category listing with breadcrumbs.

- **API:** GET /categories, GET /products?category=
- **Screenshots:** [category-silk-en.png](screenshots/category-silk-en.png)

### `/products/[slug]`
Product detail: gallery, variant chips, per-variant flash-sale price (Standard $129.00 vs Premium $199.00 on the hero), stock, description in the current locale only, reviews, add to cart.

- **API:** GET /products/{slug}, GET /products/{id}/reviews, POST /cart/items
- **Screenshots:** [product-1001-en.png](screenshots/product-1001-en.png), [product-1001-km.png](screenshots/product-1001-km.png), [product-reviews.png](screenshots/product-reviews.png)

### `(header) search`
Autocomplete suggestions.

- **API:** GET /search/suggest
- **Screenshots:** [search-autocomplete.png](screenshots/search-autocomplete.png)

### `/cart (+ cart drawer)`
Cart lines, stepper, remove, coupon, promotion lines, totals in USD and KHR.

- **API:** GET /cart, PATCH/DELETE /cart/items/{id}, POST/DELETE /cart/coupon
- **Screenshots:** [cart-en.png](screenshots/cart-en.png), [cart-km-coupon.png](screenshots/cart-km-coupon.png)


## Checkout

### `/checkout`
4-step checkout: address, shipping, payment, review; places the order with an Idempotency-Key.

- **API:** GET /users/me/addresses, POST /users/me/addresses, GET /shipping/methods, POST /checkout/preview, POST /checkout
- **Screenshots:** [checkout-address.png](screenshots/checkout-address.png), [checkout-shipping-sameday-disabled.png](screenshots/checkout-shipping-sameday-disabled.png), [checkout-review.png](screenshots/checkout-review.png), [checkout-mobile.png](screenshots/checkout-mobile.png)

### `/checkout/pay/[orderNumber]`
KHQR payment: QR, countdown, status polling, regenerate, expired overlay.

- **API:** GET /orders/{n}, POST /payments/khqr/{n}, POST /payments/khqr/{n}/regenerate, GET /payments/{id}/status (+ SSE /payments/{id}/stream), POST /payments/{id}/simulate-paid (MOCK), POST /orders/{n}/cancel
- **Screenshots:** [khqr-pending-en.png](screenshots/khqr-pending-en.png), [khqr-pending-km.png](screenshots/khqr-pending-km.png), [khqr-expired.png](screenshots/khqr-expired.png), [khqr-paid.png](screenshots/khqr-paid.png), [khqr-mobile.png](screenshots/khqr-mobile.png)

### `/checkout/bank-transfer/[orderNumber]`
Bank-transfer instructions and slip upload.

- **API:** GET /orders/{n}, POST /payments/bank-transfer/{n}/slip
- **Screenshots:** none captured for this route

## Admin

### `/admin`
Dashboard KPIs, sales trend, payment mix, top products, low stock (seed: 1027 Kampong Luong Silver Box, 1004 Hol Silk Table Runner), recent orders. The user menu's "Admin Backoffice" links here; `/admin/dashboard` redirects to `/admin` and unknown `/admin/*` paths show the 404 page.

- **API:** GET /admin/dashboard?range=
- **Screenshots:** [admin-dashboard-en.png](screenshots/admin-dashboard-en.png), [admin-dashboard-km.png](screenshots/admin-dashboard-km.png)

### `/admin/orders`
